# Desktop Image Pin（轻量桌面课表）

一个面向 Windows 10/11 的轻量桌面图片显示工具，适合把个人课表、日程表或备忘图片固定在桌面底层。

## 特点

- 图片位于普通应用窗口下方、Windows 桌面上方
- 日常模式完全鼠标穿透，不影响桌面图标和右键菜单
- 从系统托盘进入编辑模式
- 使用标准 Windows 标题栏移动，拖窗口边框或四角缩放
- 支持 SVG、PNG、JPG、BMP、WebP
- SVG 按窗口当前尺寸直接矢量渲染，不经过固定尺寸位图缓存
- 自动保存图片路径、位置和大小
- 可选开机自动启动
- 单实例运行
- 不使用 WebEngine，不需要 Java、Node.js 或网络服务

## 隐私说明

仓库不附带课表图片。图片需要用户首次启动时自行选择。

`settings.json` 和常见图片格式已加入本目录的 `.gitignore`，防止个人课表、位置和本地路径被误提交到 GitHub。

## 安装

需要 Python 3.12 和 PySide6：

```powershell
python -m pip install -r requirements.txt
```

如果本目录位于 DeskBoard 仓库内，启动器会优先使用上级目录现有的 `.venv`。

## 使用

1. 双击 `start.vbs`。
2. 首次启动时选择自己的课表图片。
3. 程序进入编辑模式后，拖标题栏移动，拖窗口边框或四角缩放。
4. 点击窗口右上角“×”，或在托盘点击“完成编辑”。
5. 完成后图片回到桌面底层并恢复鼠标穿透。

后续操作都在任务栏右下角的系统托盘菜单中完成，包括更换图片、恢复默认位置、开机启动和退出。
