# DeskBoard v0.1.0 — 学习预览版

DeskBoard 是一个面向 Windows 10/11 64 位的本地桌面信息看板，包含 Todo、课程与课表、今日日程、天气和少量金融参考信息。

这是一个学习向预览版本，源码和安装包用于学习、研究与技术探讨，不代表正式数据服务或生产级发行版。

## 主要内容

- PySide6 + 单个 QWebEngineView 的本地桌面看板。
- Todo、课程、课表、今日日程、天气和金融参考卡片。
- 中文/英文界面、主题、字体、Profile 和布局编辑。
- 首次安装默认提供唯一的 `UIBE` 课表时间段方案和“样例”学期。
- 已有数据库会自动迁移；旧的“大三上”标题迁移为“样例”。
- PyInstaller onedir + Inno Setup 安装包，卸载默认保留本地个人数据。
